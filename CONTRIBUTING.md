# Contributing to Awesome Agent Protocols

Thanks for helping grow this list. Contributions are welcome via pull request.

## What belongs here

This list covers tools, SDKs, protocols, and infrastructure for **AI agent communication** — specifically how agents send and receive messages with humans and other systems. Categories include:

- Email APIs and parsers
- MCP servers (communication-focused)
- Webhook ingestion and delivery
- Inter-agent protocols and orchestration
- Real-time messaging channels
- Message queues
- Notification routing
- Agent-to-human communication patterns

## Requirements for an entry

Before submitting, confirm your entry meets all of these:

1. **Publicly documented** — has a URL (docs, GitHub, or website) that anyone can access
2. **Clear agent communication use case** — directly useful for an AI agent sending, receiving, or routing messages
3. **Actively maintained** — last commit or update within 12 months
4. **Not a duplicate** — check the existing list first

## Format

Each entry follows this format:

```
- **[Name](https://url.com)** — One sentence description. Key features listed concisely.
```

- Lead with the most agent-relevant capability
- Avoid marketing language ("the best", "revolutionary", "cutting-edge")
- No trailing period inconsistency — pick one style and match the section
- Use plain English, not jargon

## How to submit

1. Fork this repo
2. Add your entry to the correct section in `README.md`, in alphabetical order within that section
3. Open a pull request with:
   - Title: `Add [Tool Name]`
   - Body: one sentence on why it belongs + a link to verify it's actively maintained

## What will be rejected

- Tools with no agent-specific use case (general developer tools with no path to agent integration)
- Unmaintained projects (last commit > 12 months ago)
- Entries that are just product advertisements without technical substance
- Duplicate entries under a different name
- Entries without a publicly accessible URL

## Questions

Open an issue if you're unsure whether something belongs, or want to suggest a new category.
